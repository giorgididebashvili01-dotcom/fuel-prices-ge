# ⛽ საწვავის ფასები საქართველოში

ერთი გვერდი, სადაც საქართველოს ყველა მსხვილი ავტოგასამართი ქსელის მიმდინარე ფასები ჩანს და დროში ისტორიაც გროვდება.

**კომპანიები:** Gulf · Wissol · Rompetrol · SOCAR · Lukoil · Portal

## როგორ მუშაობს

- `scraper/scrape.mjs` — Node 20 სკრიპტი, კომპანიების ოფიციალური საიტებიდან კითხულობს ფასებს (გარე დამოკიდებულებების გარეშე).
- GitHub Actions (`.github/workflows/scrape.yml`) უშვებს მას ყოველ 3 საათში და ცვლილებისას აკომიტებს `data/latest.json`-სა და `data/history.json`-ს.
- დაშბოარდი (`index.html`) სტატიკური გვერდია GitHub Pages-ზე — კითხულობს იმავე JSON ფაილებს.

## ლოკალურად გაშვება

```bash
node scraper/scrape.mjs   # ფასების წამოღება
python -m http.server 8123  # დაშბოარდი: http://localhost:8123
```

## მონაცემების ფორმატი

- `data/latest.json` — ბოლო წამოღებული სრული ფასები კომპანიების მიხედვით.
- `data/history.json` — დღეში ერთი ჩანაწერი, თითო კომპანიაზე კატეგორიების (სუპერი/პრემიუმი/რეგულარი/დიზელი/გაზი) მინიმალური ფასით.
