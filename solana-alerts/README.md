# SOL ფასის მეთვალყურე + Telegram შეტყობინებები

ლოკალურად (შენს კომპიუტერზე) ეშვება, ფასს ლაივში ადევნებს თვალს და როცა
დაწესებულ ფასს გადაკვეთს — ტელეგრამში აგდებს შეტყობინებას.
შეტყობინებებს ან ბრაუზერიდან (კომპიუტერი/ტელეფონი) აწესებ, ან პირდაპირ ტელეგრამიდან.

## 1. ბოტის შექმნა (1 წუთი)

1. ტელეგრამში გახსენი **@BotFather** → `/newbot` → სახელი → username.
2. დაგიბრუნებს token-ს: `8123456789:AAH...`
3. `cp .env.example .env` და ჩასვი token:

```
TELEGRAM_TOKEN=8123456789:AAH...
```

## 2. გაშვება

```bash
npm start          # ან: node server.js
```

Windows-ზე: ორჯერ დააწკაპე `start.bat`. macOS/Linux: `./start.sh`

კონსოლი დაგიწერს მისამართებს:

```
კომპიუტერზე:  http://localhost:8787/
ტელეფონიდან:  http://192.168.x.x:8787/
```

## 3. ტელეგრამის დაკავშირება

ბოტს მიწერე **`/start`** — chat id თვითონ დაიმახსოვრება.
დაშბორდზე დააჭირე **🔔 ტესტი** და შეამოწმე.

## 4. ტელეფონიდან

- **იგივე Wi-Fi-ზე:** გახსენი `http://192.168.x.x:8787/` (Safari/Chrome → "Add to Home Screen" და აპივით იმუშავებს).
- **ნებისმიერი ქსელიდან:** ყველაფერს ტელეგრამის ბოტიდანაც აწესებ:

| ბრძანება | რას აკეთებს |
|---|---|
| `/price` | მიმდინარე ფასი |
| `/above 120` | შეტყობინება, როცა 120$-ზე ზემოთ გადავა |
| `/below 95` | შეტყობინება, როცა 95$-ზე ქვემოთ ჩამოვა |
| `/above 120 r` | გამეორებადი (არ ჩაქრება) |
| `/list` | დაწესებული შეტყობინებები |
| `/del 3` | #3 წაშლა |
| `/clear` | ყველას წაშლა |

## პარამეტრები (`.env`)

| გასაღები | ნაგულისხმევი | აღწერა |
|---|---|---|
| `TELEGRAM_TOKEN` | — | @BotFather-ის token |
| `PORT` | `8787` | პორტი |
| `HOST` | `0.0.0.0` | `127.0.0.1` = მხოლოდ ამ კომპიუტერზე |
| `POLL_MS` | `5000` | რამდენ ხანში ერთხელ იკითხოს ფასი |
| `ASSETS` | `SOL` | `SOL,BTC,ETH` — რამდენიც გინდა |
| `FIAT` | `GEL` | მეორე ვალუტა (ლარში გადაყვანა) |
| `ACCESS_KEY` | — | პაროლი; მაშინ ბმული `http://IP:8787/?key=...` |
| `COOLDOWN_MIN` | `15` | გამეორებად შეტყობინებებს შორის პაუზა |

## როგორ მუშაობს

- ფასი მოაქვს რიგრიგობით: **Kraken → OKX → Binance → Coinbase → CoinGecko**
  (რომელიც პირველი უპასუხებს; ერთი რომ დაეცეს, ავტომატურად მეორეზე გადადის).
- შეტყობინება ფასის **გადაკვეთაზე** ისვრის, არ გატეხავს ყურს:
  თუ დაწესების მომენტში ფასი უკვე ზონაშია, დაელოდება სანამ გამოვა და ხელახლა შემოვა.
- `data/state.json`-ში ინახება შეტყობინებები — სერვერის გადატვირთვის მერეც რჩება.
- ჩვეულებრივი შეტყობინება ერთხელ გაისვრის და ჩაქრება; `🔁 გამეორებადი` — ყოველ გადაკვეთაზე.

## კომპიუტერის ჩართვისთანავე გაშვება (არასავალდებულო)

**macOS/Linux (pm2):**
```bash
npm i -g pm2
pm2 start server.js --name sol-alerts && pm2 save && pm2 startup
```

**Windows:** `Win+R` → `shell:startup` → ჩააგდე `start.bat`-ის მალსახმობი.

> ⚠️ სანამ კომპიუტერი ჩართული და ინტერნეტზეა, მანამდე მუშაობს. ჩაკეტილი ლეპტოპი ≠ შეტყობინებები.
